The Research Question

Goal: Find patterns in AI systems that prevent hallucinations and improve decision quality.

Approach: Build an autonomous AI agent with:

  • Memory of historical failures — 13 major software disasters (Ariane 5, Knight Capital, Therac-25) encoded as "trauma responses"
  • Multi-node consensus system — 3 AI agents (ZEALOT, AUDITOR, SCAVENGER) debate every decision
  • Real-world task execution — Not toy problems: actual 256-file code migration (Flutter → Svelte)

Why This Matters: Most AI systems hallucinate or make poor decisions. This experiment tests whether giving an AI "institutional memory" and internal debate creates more reliable, thoughtful behavior—and whether we can learn patterns to build better AI systems faster.

Current Test: Autonomous migration of a real production codebase. The organism plans its own work, learns from mistakes, and adapts its approach. Phase 4: Self-Planning & Autonomy.

What This Was

THE ORGANISM was a research experiment in autonomous AI reliability. Over multiple sessions spanning days, it worked on a real software engineering task: migrating a Flutter app to Svelte 5—analyzing code patterns, creating components, building state management, and most critically, debugging itself.

What made it autonomous:

  • Self-validation — Tested its own work before marking tasks complete (Bug #20 fix)
  • Symmetric state management — Saved progress on both success AND failure (Bug #18 fix)
  • Output cleaning — Removed LLM artifacts automatically (Bug #21 fix)
  • Failure learning — Tracked repeated mistakes, increased belief weights, adapted approach

Final Phase: Autonomous Quality Control
The breakthrough came when the organism learned to validate its own output. Before marking any task complete, it would check: Does the file exist? Is it valid code? Are there placeholder TODOs? This single architectural change transformed it from a tool into an autonomous agent.

Everything was logged — Every decision, every debate, every bug fix, every lesson learned. The complete findings have been documented in a 4-part article series analyzing what makes AI truly autonomous.
