Cheat Sheet

The 4 rules that make AI autonomous

TL;DR: How to build AI that runs itself

🎯 The 4 Rules

Rule #1: Save State Always

If you save when things work,
you MUST save when things fail.
Otherwise your AI has amnesia.

Rule #2: Test Your Own Work

Before marking anything "done":
1. Did it actually work?
2. Is the output quality good?
3. Are there any placeholders/TODOs?

If any check fails → Don't mark complete

Rule #3: Be Explicit

❌ "Create login screen"
✅ "Create src/routes/login/+page.svelte from lib/screens/login_screen.dart"

Don't assume AI will "figure it out"
Spell out EXACTLY what to do

Rule #4: Clean AI Output

LLMs add conversational fluff:
- Markdown fences
- "Here's your code..."
- "Let me know if..."

Always post-process to strip artifacts
Never use raw LLM output directly

🏗️ The Pattern

┌──────────────┐ │ Pick Task │ └──────┬───────┘ │ ▼ ┌──────────────┐ │ Execute Task │ └──────┬───────┘ │ ▼ ┌──────────────┐ │ VALIDATE ✓ │ ← The magic step └──────┬───────┘ │ ┌───┴───┐ PASS│ │FAIL ▼ ▼ ┌─────┐ ┌─────┐ │DONE │ │RETRY│ └─────┘ └─────┘

Most people skip the VALIDATE step.

That's why their AI isn't autonomous.

✅ Checklist

Building autonomous AI? You need:

State:

  • Saves on success
  • Saves on failure
  • Survives restarts

Validation:

  • Tests output quality
  • Has pass/fail criteria
  • Retries on failure

Tasks:

  • Explicit instructions
  • All context provided
  • Clear "done" definition

Output:

  • Explicit format prompts
  • Post-processing cleanup
  • Format validation

💡 One Insight

Autonomous = Self-validating

An AI that needs humans to check its work is just a tool.

An AI that checks its own work before declaring success is autonomous.

The difference is one validation step.

🎓 Example

Before (Not Autonomous):

def process():
    output = ai.generate()
    save(output)
    mark_complete()  # ← Hope it worked!

After (Autonomous):

def process():
    output = ai.generate()
    output = clean(output)  # Strip artifacts

    if validate(output):    # ← The key!
        save(output)
        mark_complete()
    else:
        save_failure()
        retry_later()

One if statement makes it autonomous.

🚀 Start Here

  1. Pick one task your AI does
  2. Write a validation function for it
  3. Only mark complete if validation passes
  4. Track how many tasks pass validation

You just built autonomous quality control.

Now repeat for all tasks.
